# RFC 0050: calendarify 多租户/团队共享日历与权限分级

**Status:** Pending

## Summary

为 `apps/calendarify`（RFC-0048）增加多租户/团队共享日历与权限分级——多个用户共享查看/编辑同一组日历，按角色控制权限。本 RFC 由 RFC-0048 的 Non-goals 拆出，暂缓到后续排期，先占位记录范围，不展开设计细节。

## Problem

RFC-0048 首版每个登录用户只管理自己账号下的日历，没有共享/协作场景。团队日历管理是常见需求，但涉及权限模型、邀请流程、数据隔离等额外复杂度，决定先不做，留待确认有实际需要后再细化设计。
